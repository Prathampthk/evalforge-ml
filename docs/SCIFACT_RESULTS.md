# SciFact retrieval results and validation

Measured on **2026-11-03**, not a fabricated or annotation-derived score. The full corpus contains **5,183 abstracts, 300 test queries and 339 positive judgments**. The original baseline was reproduced before changes: 72 passed/24 skipped, Recall@5 and MRR@5 both 0.954545 on 22 queries/20 passages.

Across **two complete runs**, all 18 quality-result dictionaries and ANN neighbor-agreement values were identical. Runtime varied; the tables below show the predesignated second run, not a best-of-run latency. The full-corpus TF-IDF P95 varied from 6.14 to 8.80 ms between runs, illustrating shared-host noise.

## Findings and scope

- Dense exact Recall@10: **78.33%**, versus **73.19%** TF-IDF; difference **+5.14 percentage points**. Paired 2,000-resample unadjusted 95% interval: **[+0.09, +10.32] points**. Dense NDCG@10: **0.6451**, versus **0.5924** TF-IDF. This is one scientific retrieval domain and one model/seed, not a universal quality claim.
- HNSW at full size: **78.00% qrel Recall@10**, **97.87% neighbor Recall@10 versus exact**, P95 **0.055 ms** versus flat **0.235 ms** (approximately **4.25x lower warm pre-encoded lookup latency** in this run). Exact-to-HNSW Recall difference is -0.33 points, paired CI [-1.00, 0.00] points. Neighbor agreement and relevance are distinct metrics.
- IVF trades quality for lookup speed: full-size qrel Recall@10 **71.17%**, neighbor agreement **89.63%**. MMR did not improve relevance at the prespecified lambda/fetch settings. No contrary improvement is claimed.
- Reduced corpora retain judged positives and vary real distractors; they are diagnostic subsets, not separate representative benchmark datasets. Only the 5,183-document rows use standard full-corpus conditions.
- Timings exclude text embedding, model loading, corpus encoding, and LLM generation. Serial QPS is not concurrent serving capacity; RSS deltas and serialized-memory estimates are not isolated native heap measurements. See [complete methodology](EXPERIMENTS.md).

## Final validation

- **153 tests passed, zero skipped**, on macOS arm64 / Python 3.14.2 with one FAISS thread. Before the upgrade: 72 passed, 24 skipped. API startup now uses mocks so the original 24 contract tests run without provider credentials, and 57 additional test cases extend the baseline. No live API-provider or real judge evaluation is implied.
- Black (54 source/test files), flake8, mypy (29 application/runner files), Bandit (zero findings), `pip check`, YAML/JSON/TOML parsing and `git diff --check` passed. Notebook formatting extras were not installed; Black skipped notebook cells.
- A fresh six-configuration regression run passed the frozen dataset/config/metric-aware quality gate. Both report artifact generation and rejected-regression paths are tested.
- Five installed RAGAS prompt templates were captured without network calls. Judge token/cost accounting and stale-cache rejection have local tests; judge disagreement/false-positive rates and paid inference costs remain unmeasured.
- Tests use explicit in-memory tracing exporters and disable background console export. The initial console-capture shutdown errors are avoided in the test environment; no claim of validating a live collector or fixing every production exporter lifecycle issue is made.
- Existing dependency/API deprecations remain (20 warnings). Python 3.11/GitHub Actions execution, Docker deployment, external providers and production load remain unverified here.
